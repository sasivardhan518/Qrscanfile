QR Chunk Scanner

Scan a series of QR codes. Each code's text is added to the end of one long string, in the order you scan. Press Done to read that string as base64 and save it as a file.

Get live camera scanning when the file is opened from Downloads

Chrome on Android does not allow camera access for a page opened from a downloaded file (a content:// address). The page cannot change that. Serve it from your phone instead:

  1. Install Termux from F-Droid and open it.
  2. Run termux-setup-storage and allow storage access.
  3. Run pkg install python, then cd ~/storage/downloads, then python -m http.server 8000.
  4. In Chrome, open http://localhost:8000/qr-chunk-scanner.html and tap Allow when asked for the camera.

Until then, Take photo opens your camera app and reads one code per photo.
